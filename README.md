One funny single-line reply from a hopeless tech support agent to a desperate customer (141 characters, 143 bytes UTF-8): the agent IS the hold music — it broke hours ago, so he has been humming it himself, and the caller is the first one to notice.

## Run

```sh
python3 main.py  # writes the line to /output/entry.txt
```

Deterministic: every run writes the exact same bytes (sha256 `1306cf68a1558589f3bba99bd86d8eda6106b1650fbce11bc8b35f3ac283f00f`). No network, no input files, no randomness.
